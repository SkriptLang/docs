# SkriptLang Documentation

[![Built with Starlight](https://astro.badg.es/v2/built-with-starlight/tiny.svg)](https://starlight.astro.build)

This repository contains the site source for all SkriptLang project documentation (with a heavy focus on [Skript](https://github.com/SkriptLang/Skript)).
This new site is currently in beta, so it is published to our testing website, [beta-docs.skriptlang.org](https://beta-docs.skriptlang.org).

## Project Structure

There are two primary components of our website.

### Tutorials
Our site is powered by [Starlight](https://starlight.astro.build/), so tutorials are easy to write in Markdown (or mdx for more advanced formatting). You can find them at [`./src/content/docs/`](https://github.com/SkriptLang/docs/tree/main/src/content/docs). Assets are stored at [`./src/assets/tutorials/`](https://github.com/SkriptLang/docs/tree/main/src/assets/tutorials).

### Syntaxes Page
The [syntaxes page](https://beta-docs.skriptlang.org/syntaxes/) is the viewer for all syntaxes provided by Skript and its official addons.
This portion of the site is built using a custom Starlight page, which can be found at [`./src/pages/syntaxes/[...id].astro`](https://github.com/SkriptLang/docs/blob/main/src/pages/syntaxes/[...id].astro).

Syntaxes pages are built from JSON files generated by Skript's documentation tools. These files are available at [`./src/assets/syntaxes/`](https://github.com/SkriptLang/docs/blob/main/src/assets/syntaxes). Each file is named after a specific branch or version of Skript. The `addons` subdirectory contains documentation files for the latest version of each of our official addons.


## Development

### Prerequisites
- [node 24](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

### Setup
1. Clone the repository.
```bash
$ git clone https://github.com/SkriptLang/docs
```
2. Install required dependencies.
```bash
$ npm install
```

### Building

There are two approaches you can take to building the website.

> [!NOTE]
> Please note that an internet connection is required to build the site.

#### Local Server
```bash
$ npm run dev
```
This will start a local development server to view the current site.
Most changes will be reflected in real-time, though if unexpected behavior occurs, a restart of the server is recommended.

#### Built Preview
```bash
$ npm run build
$ npm run preview
```
The first command builds a production deployment to `./dist/`.
The second starts a local preview of the build.
